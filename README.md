# Догляд за котами й собаками — продукт у розробці

Застосунок для власників котів і собак. Він збирає історію щеплень, обробок, ліків і візитів, показує наступні дії та зберігає потрібні для догляду відомості. За уточненнями від 11 листопада вага з датою вимірювання — другорядні, необов’язкові дані профілю; відсутність ваги не блокує догляд. Документи — необов’язкові вкладення в даних тварини після ядра MVP. Окремих екранів ваги й документів немає; реєстр містить п’ять екранів. Явні відмітки виконання та пропуску збережено. За погодженням від 12 листопада картка має другорядне редагування й явне скасування хибного «Готово»; запізніле виконання уточнюють фактичною датою та необов’язковою нотаткою, а після пропуску можна створити новий майбутній план зі збереженням старого пропуску.

**Перший ринок:** Україна. **Мови:** українська та англійська. **Порядок платформ:** Android → iOS → адаптивний веб; дизайн мобільних платформ планується спільно. **Стан:** продуктовий бриф MVP; застосунок ще не реалізовано.

Повні вимоги, межі MVP та відкриті питання — у [Codex.md](Codex.md).

**Активний MVP:** сім функціональних jobs J0–J6 на п’яти екранах; E1/E2 — критерії якості, S1/S2 — у [backlog](backlog.md). Погоджені виправлення flows охоплюють першу повторювану дію без історії, відновлення часткової операції, дії за недоступної історії та чернетки редакторів. Це специфікація для прототипу.
