# Здоров'я котів — продукт у розробці

Застосунок для власників 1–5 котів. Він збирає історію щеплень, обробок, ліків і візитів, показує наступні дії, зберігає назви препаратів, документи, вагу та контакти ветеринара. Чеки й інструкції зчитуються автоматично з підтвердженням результату. Нагадування та спільний догляд вмикаються за бажанням.

**Перший ринок:** Україна. **Мови:** українська та англійська. **Порядок платформ:** Android → iOS → адаптивний веб; дизайн мобільних платформ планується спільно. **Стан:** продуктовий бриф MVP; застосунок ще не реалізовано.

Повні вимоги, межі MVP та відкриті питання — у [CLAUDE.md](CLAUDE.md).
