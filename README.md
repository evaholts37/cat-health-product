# Догляд за котами й собаками — продукт у розробці

Застосунок для власників котів і собак. Він збирає історію щеплень, обробок, ліків і візитів, показує наступні дії та зберігає потрібні для догляду відомості.

**Перший ринок:** Україна. **Мови:** українська та англійська. **Порядок платформ:** Android → iOS → адаптивний веб; дизайн мобільних платформ планується спільно. **Стан:** продуктовий бриф MVP; застосунок ще не реалізовано.

Повні вимоги, межі MVP та відкриті питання — у [Codex.md](Codex.md).
