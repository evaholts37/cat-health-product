# cat: пам’ятка про скіли

Перевірено 11.11.2026. У спільному локальному середовищі є 39 активних користувацьких скілів; ще один вимкнений. Ця пам’ятка адаптована до cat і не встановлює бібліотек у проєкт. Проєктні правила — у [README.md](README.md), плагіни та їхні скіли — у [PLUGINS.md](PLUGINS.md).

## Чи викликати вручну

Зазвичай достатньо описати задачу. Агент має сам добрати відповідні доступні інструменти й прочитати їхні інструкції. Для точного вибору у Codex введи `$` та вибери назву; у Claude Code — `/назва`. Наприклад, `$ux-copywriter Перевір тексти цієї форми українською та англійською` або `/impeccable Перевір цей екран Android`.

Для плагіна використовуй повну назву, наприклад `$interfaces:variant` у Codex або `/interfaces:variant` у Claude. `afk`, `break`, `explain-interface`, `interface-review`, `state-machine`, `variant` налаштовані лише на явний виклик — приклади у PLUGINS.md. Установлення не означає, що вони працюють у кожній відповіді.

`humanizer-uk` може показуватися як `humanizer-uk:humanizer-uk`; обирай назву з меню. Скіл Agentic UX має довгу назву з пробілами, тому його можна назвати словами, а не вгадувати команду.

«Авто» нижче означає можливість добору під відповідну задачу, а не обов’язок застосовувати скіл до кожної роботи. Явний виклик більшості скілів — `$назва` у Codex або `/назва` у Claude, якщо назва доступна в меню.

## Системні скіли та скіли плагінів

| Скіл / група | Призначення і виклик |
| --- | --- |
| `openai-docs` | Офіційна документація OpenAI/Codex; авто для відповідних питань або `$openai-docs`. |
| `skill-installer` | Установлення скіла; можна `$skill-installer` і посилання. Указати спільне глобальне місце, якщо потрібний скіл для всіх проєктів. |
| `skill-creator` | Створення або зміна інструкцій скіла, а не звичайного компонента. |
| `imagegen` | Генерація або редагування растрового зображення. Це не створення нативного компонента Figma. |
| `review-agent` | Службове рев’ю конкретних змін без редагування; користувачці досить чітко замовити перевірку. |
| Скіли плагінів | У [PLUGINS.md](PLUGINS.md) описані interfaces, diagram-design, Mobbin, Notion, Drive, Pages, Sites та інші пакети. Повторно встановлювати їх окремо не потрібно. |

Системні скіли Codex не потрібно копіювати у Claude. daisyUI-скіл у cat не встановлений і не потрібний для цієї адаптації. Конкретний стек визначатиметься продуктовими й технічними рішеннями.

## Перетини й суперечності: що робити

| Випадок | Рішення |
| --- | --- |
| Особисті вимоги автора щодо React, Tailwind, shadcn, backend або ОС | Не перетворювати їх на стек cat. bencium-code-conventions уже вимкнений. |
| Кілька повних аудитів UI | Обрати один основний, спеціалізовані перевірки додавати за конкретною потребою. |
| Загальна вебдоступність і нативна мобільна доступність | Перевіряти цільову платформу; веб-ARIA не є нативним API. |
| Різні творчі напрями, правила великих концептуальних раундів і локальна правка | Назвати поточний етап і межі; не запускати великий пошук без такого запиту. |
| UX-copy, стилістичне редагування та бренд | Спочатку узгодити зміст дії й терміни cat, потім редагувати мову. Не додавати обіцянок продукту або функцій, яких немає в брифі. |
| Українська, англійська та словник іншого продукту | Застосовувати правила потрібної мови й реєстри cat. humanizer-uk — лише для української. |
| Референси конкурентів і потреби наших користувачів | Референси показують рішення; попит, зручність і гіпотези мають власні джерела перевірки. |
| Кілька архітектурних підходів | Обрати одне питання й один основний огляд; не проєктувати реалізацію лише через наявність інструмента. |
| Відсутній Figma-доступ або допоміжний скіл | Агент перевіряє доступність і називає реальну межу; повторний виклик не створить доступ. |

## Приклади запитів

> Перевір цей екран Android у межах поточного брифу cat. Збережи погоджений флоу, познач відсутні стани й дай один список зауважень. Новий стек не обирай.

> Перевір тексти форми українською та англійською через ux-copywriter. Для української за потреби додай humanizer-uk. Збережи умови, числа та зміст дій.

> Допоможи описати властивості й стани цього компонента для Figma. Використовуй наявні реєстри cat; відрізняй погоджене від пропозиції.

Це особиста пам’ятка. Обов’язкові проєктні інструкції — AGENTS.md і короткий README цієї папки; загальні правила добору підключені глобально до локальних агентів. Для веб- і хмарних сесій доступ потрібно перевіряти окремо.
